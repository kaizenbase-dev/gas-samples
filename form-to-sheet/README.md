# Googleフォームの回答を整えて転記するGASデモ

フォームに回答が入るたびに、内容を整えて「転記先」シートに1行追加するスクリプトです。架空のデータで動作を確認したデモです。

## 何をするか

| 入力のゆれ | 整え方 |
|---|---|
| 氏名の全角スペース、前後の空白 | 半角スペース1つにそろえる |
| 電話番号（全角、ハイフンなし、+81） | `090-1234-5678` の形にそろえる |
| メールの大文字、前後の空白 | 小文字にして空白を取る |
| 形式が不正な項目 | 「状態」列に `要確認：メール形式` のように理由を書く |
| 24時間以内の同じメール・同じ内容 | 「状態」列を `重複の可能性` にする |

転記先の列は `受付日時 / 氏名 / メール / 電話 / 内容 / 状態` です。「転記先」シートが無ければ自動で作ります。

## 動作確認

`Code.gs` をそのまま読み込み、GASの `SpreadsheetApp` だけを偽物に差し替えて、Nodeで6件のテストを実行しています。

```bash
node --test test.mjs
```

確認していること：電話番号とメールの整え方、正常な回答が「新規」になること、不正な項目が「要確認」になること、重複の判定（24時間以内のみ）、シートが無い場合に作ってから1行追加すること。

注意：実際のGoogleアカウント上での動作は、このデモでは確認していません。納品の際は、お客様のフォームとスプレッドシートで、サンプルの回答を送って確認します。

## 使い方（お客様の環境で動かす場合）

1. 回答の保存先スプレッドシートを開き、拡張機能 → Apps Script を開く
2. `Code.gs` の中身を貼り付けて保存
3. 左の時計アイコン（トリガー）で、`onFormSubmit` を「スプレッドシートから」「フォーム送信時」に設定
4. 初回だけ、Googleの許可画面で、ご自身で承認する（パスワードは不要です）

フォームの質問名は `氏名` / `メールアドレス` / `電話番号` / `お問い合わせ内容` を想定しています。名前が違う場合は `buildRow` の中の4か所を書き換えます。
