# 条件に合うメールをSlack・LINEに通知するGASデモ

条件に合うメールが届いたら、SlackまたはLINEに自動で知らせるスクリプトです。メールの件名・送信元はすべて架空のデータで、動作を確認したデモです。

## 何をするか

- 時間トリガー（例：5分ごと）で `checkMail` が動き、Gmailを検索する
- `RULES`（送信元・件名の条件）に合うメールだけを、Slack（Incoming Webhook）とLINE公式アカウント（Messaging API）に通知する
- 通知したスレッドには「通知済み」ラベルを付け、二重に通知しない

通知文の例：

```
【注文メール】
件名：【注文】10月分
送信元：order@example-shop.test
```

## 動作確認

`Code.gs` をそのまま読み込み、GASの `GmailApp`・`UrlFetchApp`・`PropertiesService` だけを偽物に差し替えて、Nodeで5件のテストを実行しています。

```bash
node --test test.mjs
```

確認していること：検索条件の組み立て、通知文、該当スレッドの通知とラベル付け、LINE送信（トークンがヘッダーに入ること）、通知先が未設定のときに何も送らないこと。

注意：実際のGmail・Slack・LINEでの動作は、このデモでは確認していません。納品の際は、お客様のアカウントで、サンプルのメールを使って確認します。

## 使い方（お客様の環境で動かす場合）

1. Apps Script に `Code.gs` を貼り付け、`RULES` を通知したい条件に書き換える
2. プロジェクトの設定 → スクリプトプロパティに、通知先の情報を入れる（コードには書きません）
   - Slack：`SLACK_WEBHOOK_URL`
   - LINE：`LINE_CHANNEL_TOKEN`、`LINE_USER_ID`
3. トリガーで `checkMail` を時間主導型に設定する
4. 初回だけ、Googleの許可画面で、ご自身で承認する（パスワードは不要です）

LINE公式アカウントの無料プランでは、1か月に送れるメッセージ数に上限があります。通知の件数が多い場合は、条件を絞るか、プランの変更が必要です。
