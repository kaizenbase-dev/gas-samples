# LINE公式アカウントの自動応答GASデモ

LINE公式アカウントに届いたメッセージへ、キーワードに応じて自動で返事をするスクリプトです。返事の文章・メッセージはすべて架空のデータで、動作を確認したデモです。

## 何をするか

- 「FAQ」シートの `キーワード / 返事` の表をもとに、届いたメッセージへ自動で返事をする
  - キーワードは `営業時間、何時` のように「、」で複数指定できる
  - 全角・半角、大文字・小文字、空白のゆれがあっても反応する
  - 上の行が優先される
- 該当するキーワードがないメッセージには、定型文で返し、「記録」シートに「要対応」と残す
- 届いたメッセージは、日時・ユーザーID・内容・種類（自動返信／要対応）で「記録」シートに残す
- スタンプや画像には反応しない

返事の文章は、FAQシートを書き換えるだけで変えられます（コードの修正は不要です）。

## 動作確認

`Code.gs` をそのまま読み込み、GASの `SpreadsheetApp`・`UrlFetchApp`・`PropertiesService` だけを偽物に差し替えて、Nodeで5件のテストを実行しています。

```bash
node --test test.mjs
```

確認していること：キーワードの照合、定型文への切り替え、返信先URLとトークンのヘッダー、記録シートへの書き込み、スタンプ・画像の無視。

注意：実際のLINE上での動作は、このデモでは確認していません。納品の際は、お客様のLINE公式アカウントで、サンプルのメッセージを送って確認します。

## 使い方（お客様の環境で動かす場合）

1. スプレッドシートに「FAQ」シート（1行目は見出し、2行目から `キーワード / 返事`）と「記録」シートを作る
2. Apps Script に `Code.gs` を貼り付け、「デプロイ → ウェブアプリ」として公開する（アクセスできるユーザーは「全員」）
3. スクリプトプロパティに `LINE_CHANNEL_TOKEN`（Messaging APIのチャネルアクセストークン）を入れる（コードには書きません）
4. LINE Developers のWebhook URLに、公開したURLを設定し、「Webhookの利用」をオンにする
5. LINE公式アカウントの応答設定で、自動応答メッセージをオフにする

LINE公式アカウントの設定画面での操作は、お客様ご自身で行っていただきます（画面つきの手順書をお渡しします）。無料プランでは、1か月に送れるメッセージ数に上限があります。

## 制限

GASのウェブアプリでは、LINEが付ける署名（`X-Line-Signature`）のヘッダーを読めないため、署名の検証ができません。簡易な用途向けの構成です。署名の検証が必要な場合は、Cloud Functionsなど別の構成をご提案します。
